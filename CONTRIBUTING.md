# Contributing

Thanks for your interest in contributing!

## How to Add Questions

1. Fork the repo
2. Add your questions to the appropriate file in `questions/`
3. Follow the existing format:
   ```markdown
   **Q: Your question here?**
   
   ---
   ```
4. Submit a PR

## Guidelines

- Only include questions you've personally encountered in real interviews
- Keep questions concise and clear
- No answers needed - just the questions
- Use proper markdown formatting

## New Categories

If you have questions from other categories (e.g., Java, Python, Cloud), feel free to create new files following the same structure.
